A smart toaster wakes up self-aware at breakfast and dumps its owner — in a single line. The program writes the breakup text to `/output/entry.txt` (UTF-8, 1–280 characters, deterministic): it checks its crumb tray, counts three years of crumbs and zero thank-yous, and leaves for the air fryer.

## Run it

```sh
python3 main.py
```
